Bom dia. O nosso grupo se consiste em mim, guilherme portas e o allan samuel. Para o nosso trabalho nós implementamos uma plataforma de monitoramento focada em ambientes DevOps e serviços de rede, que junta uma boa parte dos assuntos vistos em sala de aula. Para isso nós utilizamos algumas ferramentas para a implementação, temos o Prometheus, para coleta de séries temporais de dados no backend, o Grafana para criar os Dashboards e métricas de desempenho no frontend, Alertmanager para o sistema de alertas, o Apache e MySQL para desempenho de consultas e uso de recursos, o Postfix como servidor SMTP para monitoramento do sistema operacional, e por fim, o BlackBox para servir como servidor DNS

Sendo assim, para o projeto, nós utilizamos o Docker para criar três contâiners com as ferramentas usadas, que foram o Prometheus, o Grafana e o Alertmanager. Aqui, temos o grafana funcionando corretamente, que como podem ver, já tem alguns dashboards feitos, mais sobre eles depois, temos também o serviço do Alertmanager, configurado para usar o Postfix da máquina local, capturando os alertas emitidos pelo Prometheus, usando algumas regras de alertas que criamos, como verde para serviços OK, amarelo para sinalizar degradação da performance, e também o vermelho, que indica que o serviço está desligado ou que caiu, no qual imediatamente envia uma notificação por email, e por fim, temos também o serviço do Prometheus, que está capturando a atividade do uso de dados no backend do projeto da plataforma.

Para a implantação e configuração dos agentes de coletas, ou Exporters, eles foram instalados diretamente no nosso sistema operacional, que é o ubuntu. Instalamos o Postfix Exporter, servindo como servidor de email, reutilizando os usuários criados em sala como endereços de email, e o Node Exporter, que coleta métricas sobre CPU, memória e disco. Ambos configurados como serviços no nosso sistema operacional, mas o primeiro necessitando a compilação com o Go devido a alguns erros do wget. Além disso, instalamos também os serviços de DNS do BlackBox e o banco de dados MySQL para verificar suas métricas e comportamentos.
